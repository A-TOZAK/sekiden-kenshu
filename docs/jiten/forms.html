Forms ・ vs Microsoft Forms

Google フォーム

アンケートや小テストをつくる道具。先生にいちばん効くのはこれ。選択問題は自動採点、回答は自動でグラフとスプレッドシートに集計されます。

この道具のきほん

回答 → 自動採点 → 集計まで、ひとつづき

Microsoft との違い

Microsoft Forms を使ってきた先生へ

観点Google FormsMicrosoft Forms
自動採点選択問題を自動で採点同様
集計回答が自動でグラフ・表に同様
連携Classroom・スプレッドと直結Excel・Teams と連携
ひとことで：できることは近いです。Google でそろえているなら、Classroom・スプレッドシートとの相性はフォームが抜群。
授業・校務での使い方

こんなときに使えます

  • 小テスト（選択問題は自動採点）
  • ふり返りアンケート（自動でグラフ集計）
  • 保護者アンケート
ポイント：問題をつくったあと「解答集にする」を押すと自動採点に。丸つけの時間が、まるごと浮きます。
