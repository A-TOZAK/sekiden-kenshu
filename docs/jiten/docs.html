Docs ・ vs Word

Google ドキュメント

Word と同じ「文書を書く」道具。いちばんの違いは、保存して送るのではなく、クラウドに置いた1つの文書を、みんなで同時に書けること。

この道具のきほん

1つの文書を、同時に書ける

Microsoft との違い

Word を使ってきた先生へ

観点Google DocsWord
保存自動保存（クラウド）手動保存・ファイルが増える
共同編集同時に何人でも基本は1人ずつ
共有リンクを送るだけファイルを添付して送る
使う場所ブラウザ・どの端末でも主にそのPC
ひとことで：Word の機能はほぼそろっています。違いは『保存して送る』が『置いて共有する』に変わること、それだけです。
授業・校務での使い方

こんなときに使えます

  • レポート・新聞づくりを、班で共同編集
  • 1つの文書に、みんなで意見を書き込む
  • 先生の通知文・所見のたたき台づくり
つまずき対策：「保存ボタンがない」と焦らなくて大丈夫。自動保存です。上に「保存しました」と出ていればOK。
