ひとつだけ、先に種明かし

生成AIの研修は、ふつう「使い方」を教えて終わります。でも全国の統計を見ると、いま学校で起きている詰まりは、使い方ではありません。校務で生成AIを使う学校は8割を超えたのに、教職員の半数以上が使っている学校はまだ2割弱（中央教育審議会・2026年6月）。つまり「使える人がぽつぽついる」から先へ、どう進むか。今日の後半の個別の時間は、そのための時間です。
